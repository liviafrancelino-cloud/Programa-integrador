# Sistema de Programação de Produção e Montagem de Cargas

## 📌 Sobre o projeto

Sistema de apoio à decisão para o Planejamento e Controle da Produção (PCP) de uma fábrica fictícia de embalagens de papelão.

O sistema tem como objetivo auxiliar no cadastro de Ordens de Fabricação (OFs), montagem de cargas, distribuição das OFs entre máquinas e sequenciamento da produção.

## 🎯 Objetivo

Organizar a produção de forma mais eficiente, reduzindo atrasos, sobrecarga de máquinas e trocas desnecessárias de cores durante a produção.

## 📋 Principais funcionalidades

- Cadastro de Ordens de Fabricação
- Cadastro de máquinas
- Cadastro e organização de cores
- Montagem de cargas
- Distribuição das OFs entre máquinas
- Sequenciamento da produção
- Controle da fila de produção
- Registro de alterações manuais
- Indicadores de produção
